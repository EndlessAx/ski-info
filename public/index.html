数据来源说明： 实时天气 / 模型积雪深度 / 过去及未来 72h 降雪 来自 Open-Meteo 天气模型 API,由浏览器直接拉取。 Perisher / Thredbo 的缆车(及 Thredbo 雪道)开放状态 由一个自建的 Cloudflare Worker 实时抓取各雪场官方状态页(绕过浏览器 CORS 限制),每 5 分钟缓存一次。 Charlotte Pass / Selwyn 暂无结构化状态页,缆车状态请点卡片里的"见官方页面"链接查看。 摄像头：四个雪场官网都有可直接内嵌的静态图直链(每次打开/刷新会重新拉取一次快照,不是视频流),做成了缩略图网格点击放大。直播：Perisher(2路)、Thredbo(5路,YouTube)、Selwyn(1路,Twitch)官网自己也挂了真正的直播流,做成了点击展开、再点单个才播放的卡片(避免一次性加载太多视频);Charlotte Pass 官网没有直播,只有静态快照。同时保留跳转到官方摄像头页面的按钮作为兜底。 ⚠️ 直播打不开(YouTube Error 153 / Twitch 报错)：这个页面必须用 http(s) 方式访问才能播直播 —— 双击 html 文件直接打开(file:// 协议)会被 YouTube/Twitch 的防盗链机制拒绝,和域名无关,是它们不认"空来源"。本地看用 python3 -m http.server 之类起个本地服务器,或者直接用部署后的网址。摄像头快照图和天气不受影响,双击打开也能看。
