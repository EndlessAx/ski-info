Data sources: Live weather / model snow depth / past & forecast 72h snowfall come from the Open-Meteo weather model API, fetched directly by your browser. Perisher / Thredbo lift (and Thredbo trail) status is scraped live from each resort's official status page by a self-hosted Cloudflare Worker (to get around browser CORS restrictions), cached for 5 minutes. Charlotte Pass / Selwyn / all 5 Victorian resorts don't have a structured status page yet (the Worker currently only supports Perisher/Thredbo) — check lift status via the "official page" link on each card. Webcams: all nine resorts have direct, embeddable static image links from their official sites (each open/refresh re-fetches a fresh snapshot, not a video stream), shown as a click-to-enlarge thumbnail grid; Falls Creek's official site uses a single Panomax 360° camera instead. Live streams: Perisher (2 feeds), Thredbo (5 feeds, YouTube), and Selwyn (1 feed, Twitch) have real live streams on their official sites, shown as click-to-expand-then-click-to-play tiles (to avoid loading too many videos at once); the other resorts' official sites have no live stream, only static snapshots. A link to the official webcam page is kept as a fallback either way. ⚠️ Live stream won't load (YouTube Error 153 / Twitch error): this page needs to be served over http(s) to play live streams — double-clicking the html file to open it directly (the file:// protocol) gets rejected by YouTube/Twitch's anti-embedding checks, regardless of domain, because they don't accept an empty origin. For local viewing, spin up a local server (e.g. python3 -m http.server) or just use the deployed URL. Webcam snapshots and weather aren't affected and still work when opened directly.
